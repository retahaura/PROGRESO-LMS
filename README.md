# PROGRESO LMS

**Platform Pembelajaran Informatika Berbasis Web dengan Model Discovery Learning**

## Tentang Proyek

PROGRESO LMS merupakan media pembelajaran berbasis website yang dikembangkan untuk mendukung proses pembelajaran Informatika, khususnya materi jaringan komputer dan internet.

Website ini menerapkan model **Discovery Learning** yang mendorong siswa untuk membangun pemahaman melalui kegiatan eksplorasi, identifikasi masalah, pengumpulan informasi, pengolahan data, pembuktian, dan penarikan kesimpulan.

## Fitur Utama

- **Manajemen Pengguna:** Pengelolaan akun admin dan siswa.
- **Materi Pembelajaran:** Penyajian materi dalam tiga pertemuan.
- **Discovery Learning:** Aktivitas pembelajaran melalui enam tahapan Discovery Learning.
- **LKPD:** Lembar Kerja Peserta Didik untuk mendukung kegiatan eksplorasi.
- **Materi Tambahan:** Sumber belajar pendukung.
- **Tes Pemahaman:** Fasilitas pre-test dan post-test untuk mengukur pemahaman siswa.
- **Progress Pembelajaran:** Pengaturan akses materi dan aktivitas berdasarkan perkembangan belajar siswa.

## Materi Pembelajaran

1. Jaringan Lokal dan Internet.
2. Komunikasi Data dengan Ponsel.
3. Keamanan Informasi dan Proteksi Data.

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Model Pembelajaran

Website ini mengimplementasikan enam tahapan Discovery Learning:

1. Stimulation (Pemberian Rangsangan)
2. Problem Statement (Identifikasi Masalah)
3. Data Collection (Pengumpulan Data)
4. Data Processing (Pengolahan Data)
5. Verification (Pembuktian)
6. Generalization (Penarikan Kesimpulan)
